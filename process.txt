Clonado de respositorios

Sí. Pero no copiaría simplemente /var/lib/gitea del servidor viejo. Como queremos conservar compatibilidad con el Git antiguo, primero hay que identificar exactamente qué tenemos y luego migrarlo de forma controlada.

La estrategia que te recomiendo es:

No tocar el servidor viejo.
Sacar un inventario de repositorios.
Respaldar repositorios y configuración.
Crear en el Gitea nuevo los usuarios/organizaciones.
Migrar cada repositorio conservando:
historial completo
todas las ramas
tags
commits
ramas remotas
hooks si existen y son necesarios
Git LFS, si lo utilizaban
Probar clones y push desde un equipo cliente.
Solo entonces hacer el cambio definitivo.
Primero necesito saber cómo estaba montado el servidor viejo

En el servidor viejo, ejecuta este bloque:

echo "========== SISTEMA =========="
cat /etc/os-release
echo

echo "========== GIT =========="
git --version
which git
echo

echo "========== USUARIO =========="
whoami
id
echo

echo "========== PROCESOS GIT =========="
ps aux | grep -Ei 'git|gitea|gitlab|gogs' | grep -v grep
echo

echo "========== SERVICIOS =========="
systemctl list-units --type=service --all | grep -Ei 'git|gitea|gogs|gitlab'
echo

echo "========== PUERTOS =========="
ss -lntp | grep -E ':22 |:80 |:443 |:3000 |:8080 '
echo

echo "========== DIRECTORIOS =========="
ls -lah /home
echo
ls -lah /var/lib 2>/dev/null | grep -Ei 'git|gitea|gogs|gitlab'
echo

echo "========== REPOSITORIOS =========="
find /home /srv /opt /var/lib -type d -name '*.git' 2>/dev/null | head -200


No ejecutes todavía ningún mv, rm, git gc ni modificación en el servidor viejo.

Si era un servidor Git "puro"

Si el viejo simplemente tenía repositorios bare, por ejemplo:

/srv/git/proyecto1.git
/srv/git/proyecto2.git
/srv/git/proyecto3.git


entonces la migración es bastante sencilla. Podemos hacer un git clone --mirror desde el viejo hacia el nuevo:

git clone --mirror usuario@SERVIDOR_VIEJO:/srv/git/proyecto1.git


y posteriormente importar ese mirror en Gitea.

Esto conserva el historial y las referencias Git, pero no necesariamente conserva cosas externas a Git, como usuarios, permisos, hooks personalizados o configuración del servidor.

Si el viejo ya era Gitea/Gogs/GitLab

Entonces no hagamos clone --mirror todavía.

En ese caso puede existir una base de datos con:

usuarios
contraseñas/configuración de cuentas
organizaciones
permisos
repositorios
issues
pull requests
webhooks
releases
etc.

Ahí podemos hacer una migración mucho más completa.

Por eso el primer bloque de comandos es importante: quiero identificar qué teníamos antes de decidir el método de migración.

Pásame la salida del bloque del servidor viejo y te preparo el siguiente .sh para hacer la migración al nuevo sin modificar el viejo.

#!/usr/bin/env bash

set -euo pipefail

# ============================================================
# Git Server + Gitea
# Ubuntu
#
# Gitea: 1.27.3
# Git:   2.22.5
#
# IMPORTANTE:
# - No elimina repositorios existentes.
# - No reemplaza /usr/bin/git.
# - Instala Git 2.22.5 en /opt/git-2.22.5
# - Gitea queda configurado para usar ese Git.
# ============================================================

GITEA_VERSION="1.27.3"
GIT_VERSION="2.22.5"

GITEA_USER="git"
GITEA_HOME="/home/git"

GITEA_INSTALL="/usr/local/bin/gitea"
GITEA_DATA="/var/lib/gitea"
GITEA_CUSTOM="/var/lib/gitea/custom"
GITEA_REPOS="/var/lib/gitea/git/repositories"
GITEA_LOG="/var/lib/gitea/log"
GITEA_CONFIG="/etc/gitea/app.ini"

GIT_INSTALL="/opt/git-${GIT_VERSION}"

GITEA_PORT="3000"
SSH_PORT="22"

# ------------------------------------------------------------
# Colores
# ------------------------------------------------------------

RED='\033[0;31m'
GREEN='\033[0;32m'
YELLOW='\033[1;33m'
NC='\033[0m'

info() {
    echo -e "${GREEN}[INFO]${NC} $1"
}

warn() {
    echo -e "${YELLOW}[WARN]${NC} $1"
}

error() {
    echo -e "${RED}[ERROR]${NC} $1"
    exit 1
}

# ------------------------------------------------------------
# Comprobaciones
# ------------------------------------------------------------

if [[ "${EUID}" -ne 0 ]]; then
    error "Ejecuta este script como root: sudo bash $0"
fi

if [[ ! -f /etc/os-release ]]; then
    error "No se pudo determinar la distribución Linux."
fi

source /etc/os-release

if [[ "${ID}" != "ubuntu" ]]; then
    warn "Este script está pensado para Ubuntu. Detectado: ${PRETTY_NAME}"
fi

ARCH="$(dpkg --print-architecture)"

case "${ARCH}" in
    amd64)
        GITEA_ARCH="amd64"
        ;;
    arm64)
        GITEA_ARCH="arm64"
        ;;
    *)
        error "Arquitectura no soportada por este script: ${ARCH}"
        ;;
esac

SERVER_IP="$(hostname -I | awk '{print $1}')"

if [[ -z "${SERVER_IP}" ]]; then
    SERVER_IP="127.0.0.1"
fi

info "Servidor detectado: ${SERVER_IP}"
info "Arquitectura: ${ARCH}"
info "Gitea: ${GITEA_VERSION}"
info "Git: ${GIT_VERSION}"

# ------------------------------------------------------------
# Confirmación
# ------------------------------------------------------------

echo
echo "============================================================"
echo " INSTALACIÓN DEL SERVIDOR GIT"
echo "============================================================"
echo
echo " Git        : ${GIT_VERSION}"
echo " Gitea      : ${GITEA_VERSION}"
echo " Web        : http://${SERVER_IP}:${GITEA_PORT}"
echo " Repos      : ${GITEA_REPOS}"
echo
echo "IMPORTANTE:"
echo "Este script instalará la infraestructura base."
echo "NO se importarán todavía los repositorios antiguos."
echo
read -rp "¿Continuar? [y/N]: " CONFIRM

if [[ ! "${CONFIRM}" =~ ^[Yy]$ ]]; then
    echo "Cancelado."
    exit 0
fi

# ------------------------------------------------------------
# Paquetes
# ------------------------------------------------------------

info "Actualizando paquetes..."

apt-get update

apt-get install -y \
    ca-certificates \
    curl \
    wget \
    xz-utils \
    tar \
    gzip \
    make \
    gcc \
    libc6-dev \
    gettext \
    zlib1g-dev \
    libcurl4-openssl-dev \
    libexpat1-dev \
    libpcre2-dev \
    libz-dev \
    unzip \
    sqlite3 \
    openssh-server \
    git

# ------------------------------------------------------------
# Usuario git
# ------------------------------------------------------------

if id "${GITEA_USER}" >/dev/null 2>&1; then
    info "El usuario ${GITEA_USER} ya existe."
else
    info "Creando usuario ${GITEA_USER}..."

    adduser \
        --system \
        --shell /bin/bash \
        --gecos "Git Version Control" \
        --group \
        --disabled-password \
        --home "${GITEA_HOME}" \
        "${GITEA_USER}"
fi

# ------------------------------------------------------------
# Directorios Gitea
# ------------------------------------------------------------

info "Creando estructura de directorios..."

mkdir -p \
    "${GITEA_DATA}" \
    "${GITEA_CUSTOM}" \
    "${GITEA_REPOS}" \
    "${GITEA_LOG}" \
    "${GITEA_DATA}/data"

mkdir -p /etc/gitea

chown -R "${GITEA_USER}:${GITEA_USER}" "${GITEA_DATA}"
chmod -R 750 "${GITEA_DATA}"

chown root:"${GITEA_USER}" /etc/gitea
chmod 770 /etc/gitea

# ------------------------------------------------------------
# Instalar Git 2.22.5
# ------------------------------------------------------------

if [[ -x "${GIT_INSTALL}/bin/git" ]]; then

    info "Git ${GIT_VERSION} ya está instalado."

else

    info "Instalando Git ${GIT_VERSION}..."

    TMP_DIR="$(mktemp -d)"
    cd "${TMP_DIR}"

    GIT_TARBALL="git-${GIT_VERSION}.tar.xz"
    GIT_URL="https://www.kernel.org/pub/software/scm/git/git-${GIT_VERSION}.tar.xz"

    wget -O "${GIT_TARBALL}" "${GIT_URL}"

    tar -xf "${GIT_TARBALL}"

    cd "git-${GIT_VERSION}"

    # --------------------------------------------------------
    # Git 2.22.5 es antiguo.
    #
    # Para evitar incompatibilidades con OpenSSL moderno
    # del Ubuntu actual, el Git usado por Gitea se compila
    # sin soporte HTTPS propio.
    #
    # Gitea maneja HTTP/HTTPS por su cuenta.
    # Los clientes Git seguirán pudiendo conectarse a Gitea
    # mediante HTTP/HTTPS/SSH.
    # --------------------------------------------------------

    info "Compilando Git ${GIT_VERSION}..."

    make configure

    ./configure \
        --prefix="${GIT_INSTALL}" \
        --without-tcltk

    make -j"$(nproc)"

    make install

    rm -rf "${TMP_DIR}"

fi

# ------------------------------------------------------------
# Comprobar Git
# ------------------------------------------------------------

if [[ ! -x "${GIT_INSTALL}/bin/git" ]]; then
    error "No se encontró el Git instalado en ${GIT_INSTALL}/bin/git"
fi

INSTALLED_GIT="$("${GIT_INSTALL}/bin/git" --version)"

info "Git instalado: ${INSTALLED_GIT}"

# ------------------------------------------------------------
# Enlaces Git auxiliares
# ------------------------------------------------------------

ln -sf "${GIT_INSTALL}/bin/git" "${GIT_INSTALL}/bin/git-receive-pack"
ln -sf "${GIT_INSTALL}/bin/git" "${GIT_INSTALL}/bin/git-upload-pack"
ln -sf "${GIT_INSTALL}/bin/git" "${GIT_INSTALL}/bin/git-upload-archive"

# ------------------------------------------------------------
# Instalar Gitea
# ------------------------------------------------------------

info "Instalando Gitea ${GITEA_VERSION}..."

GITEA_BASE_URL="https://dl.gitea.com/gitea/${GITEA_VERSION}"

TMP_DIR="$(mktemp -d)"
cd "${TMP_DIR}"

GITEA_FILE="gitea-${GITEA_VERSION}-linux-${GITEA_ARCH}.xz"
GITEA_SHA="gitea-${GITEA_VERSION}-linux-${GITEA_ARCH}.xz.sha256"

wget -O "${GITEA_FILE}" \
    "${GITEA_BASE_URL}/${GITEA_FILE}"

wget -O "${GITEA_SHA}" \
    "${GITEA_BASE_URL}/${GITEA_SHA}"

info "Verificando checksum de Gitea..."

sha256sum -c "${GITEA_SHA}"

unxz "${GITEA_FILE}"

install -m 755 \
    "${GITEA_FILE%.xz}" \
    "${GITEA_INSTALL}"

rm -rf "${TMP_DIR}"

# ------------------------------------------------------------
# Verificar Gitea
# ------------------------------------------------------------

"${GITEA_INSTALL}" --version

# ------------------------------------------------------------
# Permisos
# ------------------------------------------------------------

chown root:root "${GITEA_INSTALL}"
chmod 755 "${GITEA_INSTALL}"

chown -R "${GITEA_USER}:${GITEA_USER}" "${GITEA_DATA}"

chmod 750 "${GITEA_DATA}"
chmod 770 /etc/gitea

# ------------------------------------------------------------
# Configuración Gitea
# ------------------------------------------------------------

if [[ -f "${GITEA_CONFIG}" ]]; then

    warn "Ya existe ${GITEA_CONFIG}"
    warn "No se sobrescribirá."

else

    info "Generando configuración inicial de Gitea..."

    cat > "${GITEA_CONFIG}" <<EOF
APP_NAME = Git Server

[server]
APP_DATA_PATH = ${GITEA_DATA}/data
DOMAIN = ${SERVER_IP}
HTTP_ADDR = 0.0.0.0
HTTP_PORT = ${GITEA_PORT}
ROOT_URL = http://${SERVER_IP}:${GITEA_PORT}/
DISABLE_SSH = false
SSH_DOMAIN = ${SERVER_IP}
SSH_PORT = ${SSH_PORT}
START_SSH_SERVER = false
LFS_START_SERVER = true
OFFLINE_MODE = false

[database]
DB_TYPE = sqlite3
PATH = ${GITEA_DATA}/data/gitea.db

[repository]
ROOT = ${GITEA_REPOS}
DEFAULT_BRANCH = main
DEFAULT_PRIVATE = private
ENABLE_PUSH_CREATE_USER = true
ENABLE_PUSH_CREATE_ORG = false

[repository.local]
LOCAL_COPY_PATH = ${GITEA_DATA}/data/tmp/local-repo

[repository.upload]
TEMP_PATH = ${GITEA_DATA}/data/uploads

[server]
LANDING_PAGE = home

[security]
INSTALL_LOCK = true
SECRET_KEY =

[service]
DISABLE_REGISTRATION = true
REQUIRE_SIGNIN_VIEW = false
REGISTER_EMAIL_CONFIRM = false
ENABLE_NOTIFY_MAIL = false

[mailer]
ENABLED = false

[log]
MODE = console
LEVEL = Info
ROOT_PATH = ${GITEA_LOG}

[session]
PROVIDER = file
PROVIDER_CONFIG = ${GITEA_DATA}/data/sessions

[picture]
AVATAR_UPLOAD_PATH = ${GITEA_DATA}/data/avatars
REPOSITORY_AVATAR_UPLOAD_PATH = ${GITEA_DATA}/data/repo-avatars

[attachment]
PATH = ${GITEA_DATA}/data/attachments

[lfs]
PATH = ${GITEA_DATA}/data/lfs

[git]
PATH = ${GIT_INSTALL}/bin/git

[git.timeout]
DEFAULT = 3600
MIGRATE = 600
MIRROR = 300
CLONE = 300
PULL = 300
GC = 60
EOF

    # Generar SECRET_KEY mediante Gitea
    info "Generando SECRET_KEY..."

    SECRET_KEY="$(
        sudo -u "${GITEA_USER}" \
        "${GITEA_INSTALL}" generate secret SECRET_KEY
    )"

    sed -i \
        "s|^SECRET_KEY =.*|SECRET_KEY = ${SECRET_KEY}|" \
        "${GITEA_CONFIG}"

fi

chown root:"${GITEA_USER}" "${GITEA_CONFIG}"
chmod 660 "${GITEA_CONFIG}"

# ------------------------------------------------------------
# Configuración SSH para Gitea
# ------------------------------------------------------------

info "Preparando SSH..."

mkdir -p "${GITEA_HOME}/.ssh"

touch "${GITEA_HOME}/.ssh/authorized_keys"

chown -R "${GITEA_USER}:${GITEA_USER}" "${GITEA_HOME}/.ssh"

chmod 700 "${GITEA_HOME}/.ssh"
chmod 600 "${GITEA_HOME}/.ssh/authorized_keys"

# ------------------------------------------------------------
# Servicio systemd
# ------------------------------------------------------------

info "Creando servicio systemd..."

cat > /etc/systemd/system/gitea.service <<EOF
[Unit]
Description=Gitea Git Server
After=network.target
After=sshd.service

[Service]
Type=simple

User=${GITEA_USER}
Group=${GITEA_USER}

WorkingDirectory=${GITEA_DATA}

ExecStart=${GITEA_INSTALL} web --config ${GITEA_CONFIG}

Restart=always
RestartSec=2s

Environment=USER=${GITEA_USER}
Environment=HOME=${GITEA_HOME}
Environment=GITEA_WORK_DIR=${GITEA_DATA}
Environment=PATH=${GIT_INSTALL}/bin:/usr/local/sbin:/usr/local/bin:/usr/sbin:/usr/bin:/sbin:/bin

LimitNOFILE=65535

[Install]
WantedBy=multi-user.target
EOF

# ------------------------------------------------------------
# Activar servicio
# ------------------------------------------------------------

systemctl daemon-reload

systemctl enable gitea

systemctl restart gitea

sleep 5

# ------------------------------------------------------------
# Comprobar servicio
# ------------------------------------------------------------

if systemctl is-active --quiet gitea; then

    info "Gitea está ejecutándose correctamente."

else

    echo
    echo "============================================================"
    echo " Gitea NO arrancó correctamente"
    echo "============================================================"
    echo
    systemctl status gitea --no-pager
    echo
    echo "Logs:"
    journalctl -u gitea -n 100 --no-pager

    exit 1
fi

# ------------------------------------------------------------
# Firewall
# ------------------------------------------------------------

if command -v ufw >/dev/null 2>&1; then

    if ufw status | grep -q "Status: active"; then

        info "Abriendo puerto web ${GITEA_PORT}..."

        ufw allow "${GITEA_PORT}/tcp"

        # SSH ya debería estar abierto normalmente
        ufw allow "${SSH_PORT}/tcp"

    fi
fi

# ------------------------------------------------------------
# Comprobación final
# ------------------------------------------------------------

echo
echo "============================================================"
echo " INSTALACIÓN TERMINADA"
echo "============================================================"
echo
echo "Gitea:"
echo "  http://${SERVER_IP}:${GITEA_PORT}"
echo
echo "Git utilizado por Gitea:"
echo "  ${GIT_INSTALL}/bin/git"
echo
echo "Versión:"
echo "  $(${GIT_INSTALL}/bin/git --version)"
echo
echo "Repositorios:"
echo "  ${GITEA_REPOS}"
echo
echo "Configuración:"
echo "  ${GITEA_CONFIG}"
echo
echo "Servicio:"
echo "  systemctl status gitea"
echo
echo "Logs:"
echo "  journalctl -u gitea -f"
echo
echo "============================================================"
echo
echo "SIGUIENTE PASO:"
echo
echo "1. Abrir:"
echo "   http://${SERVER_IP}:${GITEA_PORT}"
echo
echo "2. Crear el usuario administrador."
echo
echo "3. NO importar todavía los repositorios."
echo
echo "4. En la siguiente fase revisaremos el servidor Git antiguo"

echo "   usuarios, permisos ni historial."
